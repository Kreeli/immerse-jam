# Immerse Jam

[官网下载与图文上手](https://kreeli.github.io/immerse-jam/) · [Windows / Android 下载](https://github.com/Kreeli/immerse-jam/releases/latest) · [English](README.en.md)

免费的本地音乐分轨、练琴与多轨录音工具。拆开声部，关闭自己要练的一轨，放慢难点、设置循环，录下自己的演奏再回听。无会员、无分离次数限制，无需付费云计算。

当前版本：**Windows 0.1.11 / Android 0.1.0-preview.3**。本版修复首次安装下载、增加录音回收站和检查更新，并完善原生安装进度与设置页面。

## 选哪个版本

|                                      | Windows 10/11 x64                   | Android 9 及以上 |
| ------------------------------------ | ----------------------------------- | ---------------- |
| 本地分轨、节拍识别与乐谱自动对齐     | 支持，使用 CPU 或兼容的 NVIDIA 显卡 | 不提供           |
| 播放、变速、移调、音量、循环与书签   | 支持                                | 支持             |
| 跟练录音、多轨创作、导出             | 支持                                | 支持             |
| 导入已有分轨、完整项目、和弦谱与附件 | 支持                                | 支持             |

Android 是播放器和练琴工具，**不能在手机上分轨**。在电脑分好轨后导出完整 `.ijam`，再导入手机；也可直接导入伴奏或在创作中叠加外部音轨。普通手机和平板选择文件名以 `arm64.apk` 结尾的 APK；`x86_64.apk` 用于对应模拟器。预览包使用调试签名，升级请保留原应用和数据，避免卸载重装。

## 安装与第一首歌

1. 从上面的官方下载页下载 Windows Setup；不需要自己安装 Python、Node.js 或开发工具。
2. 选择程序目录和单独的数据目录。曲库、录音、模型、运行库与缓存都放在数据目录，卸载保留该目录；建议非系统盘并预留至少 10 GB。不要把数据目录放进程序目录。
3. 选择 CPU / NVIDIA 运行方式及需要的模型。默认六轨模型约 **667 MiB**；节拍模型和安装工具已随 Setup 提供。
4. 首次安装仍需联网：CPU 运行库约 **1–2 GB**，NVIDIA 约 **3–5 GB**，另加所选分轨模型。通常需 **5–30 分钟**，慢网络可能更久；估计包含解包与检查，已有缓存会复用。选择模型后，安装向导会进入独立的下载页面，显示当前模型、文件、大小、速度和进度，不要因进度暂时不变而反复重装。
5. 导入一首歌曲 → **拆分音轨** → 选择模式和模型 → 开始。处理在本机完成；之后可离线使用已准备好的模型。
6. 以这首歌新建跟练 → 关闭要练的声部 → 拖动波形定位 → 设置循环 → 录音回听。

**安装网络修复：**应用与安装器的文件下载使用 Windows 系统代理，也支持 `HTTPS_PROXY` / `HTTP_PROXY`。PyTorch 可在上交镜像和官方源之间测速、回退；普通依赖在清华与 PyPI 之间测试实际传输速度。设置可选择“自动 / 优先国内镜像 / 优先官方”，优先源失败仍会尝试备用源。默认六轨模型提供固定版本的备用地址，各来源都校验同一个 SHA-256。缓存无进展时会结束当前尝试并切换来源。

安装失败时点“重试”，保留已下载内容。具体原因见**数据目录中的 `installation.log`**，可在 [Issues](https://github.com/Kreeli/immerse-jam/issues) 附上有关段落，先去掉私人路径等信息。设置中的运行环境入口可补装或修复；冷启动检查会显示“正在检查环境”，不需要立即重装。

设置中提供 **检查更新**。Windows 下载并校验 Setup 后，由用户点击安装，继续使用原数据目录；Android 跳转对应 APK 下载，安装需系统确认。GitHub 接口受限时改读官网版本清单。当前未做无提示后台升级。

## 练琴与创作

- **波形**：播放头固定在中央，波形随播放平移；只拖动定位，单击不会跳转。手机双指缩放，电脑 `Ctrl + 滚轮` 改变时间窗口。顶部显示书签、备注与循环边界，长备注省略。
- **混音**：每轨独立音量、声像、关闭声音与组合选听，支持独立变速 / 移调、节拍器、预备拍。模型产生的几乎无声声部会标注，不会擅自删轨。
- **跟练**：可在“分轨伴奏”和“录音含伴奏”之间切换，最多挂载两条录音；其他尝试保存在项目录音库。“移回录音库”保留文件。
- **创作**：从空白或歌曲开始，多轨叠录；多个分轨可作为可折叠分组加入，并有分组总音量。可以导入外部分轨、导出单轨或当前混音。
- **录音保护**：删除前确认，原文件保存在该项目的录音回收站，可立即撤销或从录音库恢复。导出的项目不包含回收站内容。删除整个项目会连同其回收站一起处理。
- **和弦与乐谱**：多份可编辑和弦谱、任意文字填格、跟随播放、Guitar Pro / MusicXML / MIDI 与同步点。复杂和弦、自由速度、变拍曲和改编谱需听音修正。

歌曲和设置自动保存。普通歌曲、跟练和创作是独立副本，删除源歌曲不会连带删除已有练习。Windows 浏览曲库仍可播放；Android 返回应用列表会停止播放，切到系统后台或锁屏可继续播放。录音被后台、电话或设备切换打断时，会结束并保存已收到的内容。

延迟校准采用跟拍法，结果包含人的跟拍偏差，**不是声卡纯硬件延迟**。建议耳机监听、短促拍手 / 扫弦，试听前后效果再应用；换设备后重新校准，可手动微调。

## 项目与设备互传

完整 `.ijam` 保留分离结果、录音、分组、和弦谱、附件和练习设置。另可导出 WAV / MP3。支持导入 `.aum` 或只读扫描 Audio Jam 本地曲库，迁移采用复制，不修改原库。

设备需连接**同一局域网、同一 Wi-Fi 或热点**。电脑扫码分享可由手机浏览器参与；应用间也可交换连接码进行加密直传。没有 TURN 云中转，不承诺跨运营商直连。网络有设备隔离时，请改用个人热点或项目文件。

局域网扫码使用 HTTP，适合可信的 Wi-Fi / 热点。新版使用两分钟、一次性的邀请，连接后换成短时会话，接口不再通过 URL 传令牌，并只监听选中的本地网卡。不要公开配对截图或链接。它是项目传输，不会自动合并不同设备上的编辑；接收新版本会保留副本。

## 已知边界

- 大工程对设备性能仍有要求。Android 采用有界音频窗口，避免整曲解码占满内存；非原速 / 移调跳转仍可能有短暂停顿，不能保证所有低端设备完全无感。
- 默认模型与其他社区权重保留各自使用条件。项目只公开镜像已明确授权的安装工具与节拍资源，其余权重不随 Setup 分发。维护备份、离线目录与来源见 [下载资源说明](docs/DOWNLOAD_RESOURCES.md)。
- 未签名 Windows 安装包可能出现系统提示；请核对官方仓库下载页及 `SHA256SUMS.txt`。个人录音和曲库不在仓库或安装包中。

## 从源码开发

需要 **Windows x64、Node.js 24 和 npm**：

```powershell
npm ci
npm run check
npm test
npm run build
npm run dev
```

`npm run prepare:runtime` 准备私有 Python 分析环境；Android 构建见 [Android 开发说明](platforms/android/README.md)。打包前本地应已有经过校验的 uv 和 Beat This! 缓存；`npm run package` 生成 Setup，构建过程本身不会自动下载大模型。

仓库根目录的 `Start-Immerse-Jam.cmd` 是**已有开发构建的启动入口**，指向 `release/win-unpacked`，沿用 `.runtime/data`；单独 clone 源码不会自带这些构建和私人曲库。给朋友安装请发 Setup。

CI 运行类型 / 语言检查、Node 单测、构建、共享界面和维护中的 Electron 冒烟检查。界面检查使用生成的临时音频和隔离项目，不需要个人音乐；需要真实模型、麦克风或 ADB 的验证为手动项目。命令、前置条件和历史脚本状态见 [测试说明](docs/VALIDATION.md)，不用把整套 E2E 每次都跑一遍。
