# Immerse Jam

[English](README.en.md) · [开发结构](docs/ARCHITECTURE.md) · [项目格式](docs/DATA_FORMAT.md) · [测试记录](docs/VALIDATION.md)

Windows 10/11 x64 本地分轨、练琴与多轨录音应用，当前版本 **0.1.5**。分离、节拍／和弦识别及乐谱对齐在本机运行，无会员和分离次数限制。

## 安装与首次使用

从 [Releases](https://github.com/Kreeli/immerse-jam/releases) 下载 Windows 安装包。播放无需预装 Python、Node.js 或开发工具。录音导入、归一化和混音导出首次需要时，程序自动下载并校验自己的 FFmpeg。

分轨／分析前，在“设置与模型”选择 NVIDIA 或 CPU，点击“自动安装环境”。程序安装私有 Python 和推理依赖，不依赖系统 Python；NVIDIA 路径需要兼容的显卡驱动。模型可提前点击下载，也可首次使用时自动下载。首次准备需要联网，之后推理可离线进行。运行库、缓存、模型和歌曲分轨合计可能占数 GB，请保留空间。

源码中的 `Start-Immerse-Jam.cmd` 是开发工作区入口，需要先构建独立程序；发给朋友请用安装包。仓库和安装包不包含个人曲库、录音或模型权重。

## 练习与录音

音乐库与练琴工程分开管理。侧栏“练琴模式”以列表显示跟练／创作工程，可筛选全部、跟练或创作；没有工程时可在中央新建。新建时选择音乐库歌曲及一组分离结果，确认后复制成独立工程，取消不会创建。创作还可以选择空白工程。工程中的设置、录音和文件独立于音乐库源歌曲。

浏览音乐库、收藏、歌单或工程列表不会停止当前播放，底部播放条始终保留，点击名称返回播放界面。音乐和工程都有删除入口，确认后移至系统回收站；删除源歌曲不会连带删除已有工程副本。

跟练内部可一键切换“分轨伴奏”和“录音含伴奏”：前者回听独立演奏录音并叠加可调节分轨；后者有挂载录音时默认只听录音，避免伴奏加倍。两者录制时均由右侧分轨控制伴奏，跟练录制不播放之前的尝试；创作模式则保留多轨叠录。

- 多轨混音、独立变速／移调、音量、声像、实时电平和混音预设。“选听”允许组合多轨，“关闭声音”与同轨选听互斥。点音轨名称切换单轨波形，再点一次回总混音；单色波形滑动窗口可拖动定位。
- 一个按钮依次设置循环段落的开始和结束；段落和标记点可命名、跳转及删除。空格播放／暂停，方向键定位，L 设置循环位置，M 添加标记点。
- 智能节拍器跟随检测节拍和强拍，有独立音量；预备拍后从最近节拍开始。支持手动 BPM、半速／倍速和 Tap 校准。
- 录音可选输入源、伴奏输出和输入声道。程序不将麦克风直接返送扬声器；使用效果器或声卡直接监听乐器。
- **只录乐器**：保存所选输入，不把内部伴奏混进录音。**声卡已混音**：用于声卡／效果器已通过 AUX 等混入伴奏的输入，保存完整输入，默认关闭新录音声音，避免回听重复叠伴奏。
- 项目录音库保存多次录音；**练习最多挂载两条**，两条均可听。移回录音库保留文件；删除则移除对应文件。可批量导入、命名、调整开始时间和偏移，不同长度部分保持空白。
- 沿用声像把原分轨放左边、演奏放右边，其他伴奏保持双声道。
- **创作模式**从空白工程开始，多轨叠录、导入、混音和导出，不受练习两条挂载限制。

“跟拍测延迟”先听四拍，再跟八拍发出短促扫弦或拍手声。建议戴耳机，避免点击声通过 AUX／扬声器进入录音。结果包含人的跟拍偏差和音频路径延迟，**不是声卡纯硬件延迟**；按输入／输出组合保存，可手动微调，每条录音也可单独校正。变速／移调录制会归一回歌曲时间轴，并保留原始录音。

## 分轨、和弦与乐谱

六种分离模式：基础四轨、完整六轨、主奏／节奏吉他、鼓、贝斯、主唱／和声。默认六轨 BS RoFormer SW（约 667 MiB），可选 HT Demucs 等；专用模式按需下载额外模型。模型输出清单经过校验，不以轨数猜声部。自定义模型见 [CUSTOM_MODELS.md](docs/CUSTOM_MODELS.md)。不同模型结果独立保存、切换和重命名，音轨为可直接取出的 WAV 文件。

和弦谱跟随播放，支持多份自制谱、四小节排版、任意移动／互换和弦、空位、段落名和小节校准；每小节最多两个和弦，可调整第二和弦起拍。复杂和弦、弱起、自由速度及变拍曲需要听音修正。

支持 Guitar Pro、MusicXML、MIDI、谱面高亮、自动对齐和同步点修正。MIDI 使用基础合成音色，尚不覆盖全部 Guitar Pro 技法。复杂改编的自动对齐仍需检查。

## 项目与互传

结构为“项目 → 模型分离结果 → 音轨”，另有录音库，详见 [数据格式](docs/DATA_FORMAT.md)。完整 `.ijam` 工程保留多组模型结果、录音库、谱面及练习设置；另可导出原曲／分轨和当前混音 WAV／MP3。

可只读扫描 Audio Jam 本机曲库并复制迁移，也支持 `.aum` 导入，不修改原数据库。云端未下载的媒体无法凭空迁移。

同一 Wi‑Fi／热点可扫码互传，手机浏览器可参与。远程用 WebRTC 直传和手动交换连接码、公共 STUN，无配置中的 TURN 中转；部分 NAT／运营商网络可能无法连接，可改用局域网。跨运营商和真实手机互传仍需进一步验证。

Android 原生版、蓝牙、远程断点续传和跨设备编辑冲突合并尚未实现，当前优先 Windows。

## 界面与开发

设置可即时切换简体中文／English、暗色／浅色／跟随系统，以及玫瑰、蓝、绿、紫强调色。歌曲名、录音名和自制和弦保持原文。

使用 Node.js 24、npm 和 Windows x64：

```powershell
npm ci
npm run check
npm test
npm run build
npm run dev
```

`npm run prepare:runtime` 准备私有分析环境，`npm run test:backend` 验证后台。`npm run package` 生成 NSIS 安装包，`npm run package:portable` 生成独立目录。Playwright 界面测试默认生成隔离项目，不使用个人曲库，命令与边界见 [测试记录](docs/VALIDATION.md)。
