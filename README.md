# Immerse Jam

Windows 10/11 x64 本地分轨与练琴应用，当前版本 0.1.3。使用独立实现的界面和播放引擎，保留 Audio Jam 的主要操作布局。

## 这台电脑直接使用

双击 `Start-Immerse-Jam.cmd`，会打开已经打包的独立程序，并使用本工作区内已经准备好的运行环境、模型和迁移后的曲库。此入口不需要安装 Node.js 或 Python。

本机的 Audio Jam 曲库已复制迁移 26 首；另有 1 首缺少本地原曲与分轨。原数据库与媒体文件保持完整。迁移数据位于 `.runtime/data`，不会被放进分享用的安装包。

## 发给朋友安装

分享 `release/Immerse Jam Setup 0.1.3.exe`。安装后首次打开，在“设置与模型”选择 NVIDIA 或 CPU 引擎，点击“自动安装环境”。程序会下载自己的 Python、推理库和所需模型，不使用电脑原有的 Python 环境。后续分轨、分析和播放可以离线进行。

建议保留足够的磁盘空间：NVIDIA 运行库、下载缓存和几个模型合计可能需要数 GB；歌曲分轨另占空间。可在“设置与模型”点击“下载模型”提前下载，或在首次分轨时自动下载；显示进度，失败后可重试并继续已有下载。安装包不包含私人曲库、参考软件的演示媒体或模型权重。

## 0.1.3 更新

- 波形改用单色填充包络。采样区间固定在歌曲时间线上，随窗口平移，避免播放时反复重组包络带来的闪动。
- 打开歌曲时在后台线程预先生成各音轨波形，并缓存实际混音波形。点击右侧音轨切换到单轨，再点一次回到总混音；调整混音后会更新总波形。
- 用一个按钮设置循环段落：第一下设置开始，第二下设置结束并保存。循环段落和标记点各有管理列表，支持命名、跳转和删除；快捷键 L 设置循环位置，M 添加标记点。
- 音轨按钮改为“选听／关闭声音”。保留多轨组合选听；同一轨道两个状态互斥，以最后点击的为准。新增当前实际信号的音量指示，随声音、停顿和音轨控制变化。
- 删除持续节拍器，只保留可设置 BPM 和拍数的预备拍；它仅在主动开始播放前响起。
- 分析改用 [Beat This!](https://github.com/CPJKU/beat_this) 在本机识别节拍和小节首拍，首次自动下载约 77 MiB 权重，也可在模型管理中预先下载。自动 BPM 标注为估计值，可手填、半速／倍速校准或 Tap 测速；模型暂不可用时退回基础估计。识别仍需结合听音检查。
- 应用图标、窗口图标与侧栏标志换为提供的乐器波形图片。

## 0.1.2 更新

- 和弦页默认跟随播放，自动滚动到当前小节；可关闭跟随进行编辑。
- 可以新建多份自制和弦谱、命名、自动保存。和弦可移到任意小节的空位，也可互换；支持添加／删除空位、编辑／删除和弦，每小节最多两个和弦。删除和弦会保留空位，删除空位会合并位置。
- “小节校准”支持 BPM、拍号、首拍秒数、识别节拍／固定速度，以及将所选小节起点对齐到当前播放位置。双和弦小节还可指定第二和弦从第几拍开始。前奏单独标记；改动小节线会保留已填写的和弦。
- 默认波形来自当前实际混音，考虑分轨音量、选听、关闭声音和声像；点击右侧音轨名称可以切换单轨波形。
- 波形采用 10／20／30／60 秒滑动窗口，播放位置固定在中央，左右拖动可移动时间位置；下方进度条仍可跳转整首歌。
- 每次分离追加独立结果。可在右侧“分离结果”选择不同模型、不同轨数的版本，重命名结果或音轨，切换时保留播放位置。项目导出／互传会包含所有已保存的分离结果。

### 项目文件结构

```text
projects/项目编号/
  project.json                  项目、所有结果索引、自制和弦谱和练习设置
  media/                        原曲
  results/
    模型名或自定义结果名--编号/
      result.json               这组结果的模型、模式和音轨信息
      tracks/
        vocals.wav
        drums.wav
        ...
```

右侧“结果文件夹”可以直接打开对应目录，里面的音轨是可直接复制使用的普通音频文件。结果重命名会同步更新文件夹和引用。旧曲库会自动整理结果索引、保存升级前项目清单，并保留旧媒体；可识别的完整历史分离结果也会恢复到列表中。旧版本没有记录的模型名称会显示为历史模型，可自行重命名。

自制谱和识别结果相互独立。重新识别后，可在和弦谱下拉列表选择“最新识别结果”；已有自制谱会保留。自动检测的小节线需要听音检查，变拍、自由速度或弱起录音可以通过校准修正。

修复超过三分钟歌曲分轨时缺失音频检测工具的错误；默认 PyTorch 模型不再显示无关的 ONNX 显卡警告。入口统一为“开始分析”。播放区改为大波形，移除中央和弦、指法图与均衡器；和弦页改为可编辑的小节排版；模型管理增加显式下载、进度和校验按钮。

## 已实现

- 六种分离模式：基础四轨、完整六轨、主奏／节奏吉他、鼓、贝斯、主唱／和声。前后两阶段模式会按所需声部选择专用模型。
- 同一时钟的多轨混音、音量、多轨选听、关闭声音、声像、实时音量指示、混音预设、独立变速和移调。
- 大波形拖动定位、命名循环段落与标记点、预备拍、按住试听、空格与方向键快捷操作。
- Guitar Pro、MusicXML 和 MIDI 导入，谱面预览、跟随高亮、同步点编辑、MIDI 基础合成播放。
- 本地和弦／调性／BPM 分析、和弦修正、手动 BPM 与 Tap 测速。
- 收藏、最近练习、歌单、图片／PDF 附件、笔记、视频预览与麦克风录音。
- 无损项目导出、原曲／分轨分别导出、按当前音量／声像／速度／移调导出 WAV 或 MP3 混音。
- `.aum` 导入；直接读取本机 Audio Jam 的 AumDb 数据库，预览哪些歌曲及声部已下载，再复制迁移。
- 局域网／手机热点二维码互传，默认原曲与分轨；接收方浏览器也可上传音频或歌曲包。
- WebRTC 加密直传，通过交换连接码配对；发送方选择歌曲，接收方选择清单并确认导入，接收后校验 SHA-256。
- 自定义 ONNX 波形、SCNet、RoFormer 模型导入；清单、校验值、声部名称和实际试运行输出必须匹配。
- 无会员、无次数限制；侧边栏自愿打赏入口。

歌单操作：在歌曲标题上右键，输入歌单名称；曲库侧边栏会显示对应歌单。双击标题可重命名歌曲。

## 自动对齐与实际边界

已按选择 B 实现本地自动对齐：先由乐谱展开反复并生成 MIDI，再将音高特征与原曲匹配，生成单调时间映射，处理演奏速度变化。显示低可信度片段，并提供整体偏移和同步点修正。

它不是对任意录音、任意改编都能准确对齐的保证。只有单个声部的谱子、长休止、调音不同、录音多出或省略段落时，需要检查自动结果。MIDI 目前使用基础合成音色；尚未加入完整的采样音源与全部 Guitar Pro 演奏技法。

和弦识别结合谐波特征、节拍和连续性约束，按音乐节拍合并和弦。和弦页默认每行四小节，可修改拍号、校准小节线、任意移动和弦、命名段落和双击修正和弦。排版自动保存，拖动只调整显示位置。复杂爵士和弦、转位与有噪声录音仍可能需要修正。

远程直传已通过本机双窗口完整传输测试；跨运营商、对称 NAT 等网络尚未完成真实双设备验证。使用公共 STUN 获取连接候选地址，没有配置付费中转，因此不能保证所有外网都能连接。连接失败可改用同一 Wi‑Fi／手机热点。

Android 原生应用尚未开发；目前手机可以通过浏览器参与局域网互传。蓝牙传输、远程中断续传和双向练习数据冲突合并尚未实现。

## 模型选择

默认六轨为 BS RoFormer SW，权重约 667 MiB；兼容备选为 HT Demucs 六轨，权重约 52 MiB。主奏／节奏和主唱／和声另按需下载专用模型。SCNet 四轨是可选候选，尚未完成完整质量验收。

默认模型覆盖练琴所需六类声部，并已在本机验证；没有宣称它在所有分离任务中排名第一。不同架构与模型的公开分数不可直接等同于每首歌曲的听感。

自定义模型格式说明见 [docs/CUSTOM_MODELS.md](docs/CUSTOM_MODELS.md)。依赖许可证见 `assets/licenses/`，第三方模型权重独立下载，来源信息保存在模型目录与内置目录定义中。
