## 工程、封面和菜单

音乐库、跟练 / 创作、分类页面和 Android 列表共用一个“更多”菜单。打开项目、编辑资料、移动分类、删除采用统一样式；移动分类使用子菜单，不再在卡片内展开原生下拉框。菜单可用键盘、点外部关闭，同一时间只打开一组。

“编辑项目”支持名称、艺术家、简介和封面；名称最多 120 字，简介最多 2000 字。取消不写入，保存只提交资料字段，先等已有编辑落盘，不把旧音轨列表写回。编辑正在播放的项目不重建音频节点。各类项目在两端列表都有入口，封面显示在库卡片、跟练列表和桌面播放器头部，简介在列表中作省略显示。

图片从本机选择 JPG / PNG / WebP，单张输入上限 20 MB；在本机按中心裁成不超过 384 × 384 的 JPEG，保存的数据 URL 上限 180000 字符。工程 `cover`、`description` 与分类 `cover` 均为可选字段，两端存储验证其类型、长度、格式及图片文件头，不接受外部 URL、SVG 或任意文件路径。“恢复默认图标”清空封面字段，旧工程无需迁移。

小图内嵌在工程清单中，随现有 `.ijam` 导出 / 互传流程携带，不依赖原照片路径、网络图片服务或额外媒体引用。分类图片保存在各设备本机的 `folders.json`；单个工程分享不会复制对方整套分类结构。Android 原生 WebView 补齐系统图片选择器，取消选择可返回编辑窗口，不申请整盘照片权限。

分类可新建、改名、设置或移除封面。Windows 从侧栏进入分类后编辑；Android 从“分类 → 管理分类”编辑，并可筛选项目、移动到分类。删除分类仍需确认，工程及音频保留。侧栏文件夹统一左对齐，与其他导航具有相同的图标和文字起点；长名称省略，不撑宽侧栏。

平板软键盘会遮住编辑窗口底部的问题已修正：通过 visualViewport 调整新资料弹窗的可见高度和位置，保存按钮可以滚入可见区域。

## 录音和多轨创作

录音前后始终保留同一颗录音按钮和播放栏结构。录制时圆点变成停止方块，停止后恢复圆点；不追加计时、电平、设备名称或第二套停止栏。原先录制态阻断桌面播放栏指针事件的规则单独为停止按钮放行，其他不允许的跳转控件仍禁用。

实时录音波形使用固定显示增益 3，便于观察较小输入；不改变采集 PCM、电平、延迟校准或最终文件音量。总波形和已有音轨包络逻辑保持不变，不做随帧归一化。

绘制参数 `amplitudeScale` 是除数，因此最终设为 `0.36`，相当于旧除数 `1.08` 的三倍显示增益。

创作页的旧 `.track-control` 三列布局会把新版两列音轨条重新摆乱，已针对创作区域清除冲突的网格位置，按“电平条 + 名称 / 推子”稳定排列。多轨源工程仍作为分组，保留分组总音量、选听 / 静音、内部声部、单独展开波形和叠录；没有变回主波形多色堆叠或六轨概览。

按作者最后要求，源工程默认不显示波形；第一层展开总波形，第二层“显示所有音轨”才挂载内部列表，第三层由各音轨名称展开自己的波形。录音电平条单独移到右侧，避免压住左侧话筒 / 展开图标。

## 输入、颜色及弹出层

Android 设置增加箭头、圆环、十字、系统四种鼠标指针选项。自定义指针只响应 mouse 类型指针事件，移动 / 点击时显示，2.2 秒不操作、触摸、离开应用或失焦时隐藏。位置只更新浮层变换，不触发整页 React 刷新；原生 WebView 的鼠标图标接口同步隐藏重复的系统指针。选择系统指针时恢复系统行为。该功能与设置入口仅在 Android 启用，手写笔 / 触摸不生成自定义鼠标。

空格播放 / 暂停，左右方向键移动 5 秒，L 设置循环起止，M 添加标记，Ctrl＋滚轮缩放。两端使用同一判断函数，兼容 Android 原生事件只有 key、code 为空的情形。输入框、可编辑内容、弹窗和展开的菜单不会被这些快捷键抢占；修饰键组合及长按空格也不会反复触发动作。

两端外观设置提供波形预设色、任意六位 HEX 色值与恢复默认；Windows 还可用系统颜色选择器。颜色保存在本机偏好中，所有共用波形绘制器即时生效，不改变音频或项目数据。Android 的指针 / 波形颜色偏好与个人主题一样按设备保存，不跟着音乐工程覆盖对方设置。

“重命名分离结果”改为统一弹窗，保存按钮具有完整内边距；“以这首歌创建”使用标准菜单，新建跟练 / 创作沿用统一弹窗和选择控件，不受顶栏按钮重置影响。弹窗均可取消，仍按原有方式建立独立项目。

返回已看过的歌曲时复用会话内的真实混音包络，并在音频载入期间先显示已有预览。缓存上限为 16 项 / 100 万峰值点，不缓存整首 PCM；媒体版本、文件路径、音轨状态、声像、时间位置或主音量变化会失效。首次启动 / 首次打开仍执行必要解码，这项改动不承诺冷载入瞬时完成。
