# 统一分离结果管理菜单

按作者要求，Windows / Android 共用一个与其他控件同主题的下拉菜单，只提供选中、重命名、删除。删除前确认；原曲为固定选择项，不提供改名或删除。移除菜单外的标签、文件夹按钮、模型日期和追加的重复轨数。两端均置于控制台顶部，Android 不再在“伴奏与录音设置”内重复显示一套结果管理。

新增 `result-delete` 契约、桌面与 Android 实现，网页演示同步支持菜单行为。删除非当前结果保持选择；删除当前结果回到原曲，保留录音与已创建工程。仅移动不再被原曲、其他结果、录音、附件、创作分组引用的媒体到数据目录 `trash/results/<随机编号>`，保存删除前的清单；保存失败会还原移动的文件和项目清单。该回收目录不随工程导出，也不新增 UI 入口。当前没有结果还原 / 清空回收目录按钮，删除不会立即释放回收文件占用的磁盘空间。

Android 同时修复 `result-select` 对空值的处理，现可切回原曲；名称校验与桌面一致，为 1–120 字。结果操作先等待待保存编辑完成，避免旧混音状态回写。现有交互辅助脚本同步改成菜单选择 / 改名，未追加整套界面审查。

本轮完成类型 / 文案 / 桌面语法与双端构建；一项针对性删除检查覆盖非当前 / 当前结果、共享媒体保留、预设引用清理和保存失败还原。桌面与平板使用临时工程截取实际菜单，平板原曲切换已实际执行，随后移除临时工程；未在私人项目上执行删除。未运行新的 Android instrumentation 或长时间播放 / 推理检查。

Windows 已更新原 `Start-Immerse-Jam.cmd` 入口，平板覆盖安装成功。APK、截图与产物清单位于 `release/result-menu-review`；前版 Windows / APK 为同目录的 `before-win-unpacked` / `before-Android.apk`，前版源码为 `d4a60c8`。无新 Setup、推送、公开 Release 或网站部署。
