# Immerse Jam Android 0.1.0-preview.1

待验收说明草稿，未发布。本轮不重新生成或上传 APK。输入音频及单次录音最长 44 分钟，另有播放和推理内存保护。

首个 Android 预览版源码，适配 ARM64 手机和平板。入口侧栏、大波形、音乐库、跟练／创作及共享播放／和弦编辑界面已接入原生存储。系统返回先关闭面板和弹窗，再返回上一级，根音乐库两次返回退出。

随包提供约 64 MiB 的 UVR 人声／伴奏模型，可离线运行；SCNet 四轨模型约 50 MiB，按需下载。文件体积与所需运行内存并不成比例。模型固定 SHA-256、声部和形状；推理独立进程、单任务分块，检查内存／存储／温度，支持取消和保留旧结果。后台完成结果、中断录音可恢复。

这是预览版本，尚未完整覆盖 Windows：移动端自动节拍／和弦模型、六轨及专用吉他／主唱分离、变速录音归一化、混音导出与应用内扫码／远程互传仍在迁移。当前可以导入电脑的完整 `.ijam` 使用已识别节拍、谱面与分轨，并通过系统分享导出。完整清单见 [Android 功能表](https://github.com/Kreeli/immerse-jam/blob/main/docs/ANDROID.md)。

Android 15 模拟器通过手机／平板布局、返回、播放、录音、存储恢复及实际两轨／四轨模型推理。实体 ARM64 手机的速度、USB 效果器和长时间稳定性尚未验收。

普通 Android 手机／平板请用 `arm64-v8a.apk`；`x86_64.apk` 用于模拟器。当前为调试签名预览包，正式签名和商店发布尚未配置。卸载前导出个人内容。原创代码为 PolyForm Noncommercial 1.0.0，模型与组件保留各自许可。
