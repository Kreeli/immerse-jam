# 布局菜单、和弦谱与乐谱显示修订

本轮按作者反馈继续调整现有界面，不发布 Release，也不更新网站。

- 音乐库、收藏、分类页共用文字下拉菜单切换列表 / 方格，保留布局偏好。分类封面与音乐库统一：方格 64 px、列表 44 px；收藏本来复用音乐库，同步保持一致。
- 和弦谱选择、新建、改名与删除统一进入 `ChartPicker` 菜单。去掉常驻名称输入框、和弦库、撤销与长篇操作说明；每行数量、小节校准、跟随、识别放在紧凑的一排。和弦可在格内自由输入，原有桌面单击已有和弦定位、双击编辑保留。窄窗口的四列使用可收缩宽度，避免第四列被侧面板挡住。
- 谱纸使用独立浅色背景与深色字色，alphaTab 的音符、谱号、标题、谱线与小节号明确配置颜色，避免通用主题变量把字变白。保留导入、看谱与视觉跟随；移除 MIDI 发声开关、调度与合成，旧工程中开启过该标志也不发声，兼容字段不删除。
- 按作者后续取舍，分离结果选择器移回控制台，顶部仅保留歌曲信息与窗口按钮。“已保存”、新建跟练 / 创作和拆分音轨放到下一行工具栏，与导出、面板开关相邻；较窄窗口允许工具栏换行。
- Android 的“伴奏与录音设置”使用与卡片相同的 16 px 内边距，展开箭头、文字和相邻标题对齐；内部设置避免再次叠加左右缩进。

前期针对性检查已覆盖：三处布局下拉切换与封面尺寸、和弦新建 / 自由输入 / 取消编辑 / 改名 / 删除确认、浅暗主题乐谱颜色、旧 MIDI 设置不再发声。一次完整隔离界面检查通过。之后小窗口样式修订的重复脚本在重载后未重新打开工程便寻找“乐谱”，因此脚本超时；没有将它算作最终整套通过，也没有据此扩大应用修改。

作者最后明确要求修改后直接展示、不再审查；最终对齐改动仅重新构建两端、同签名更新平板并截取实际界面，不追加代码审查或整套自动回归。预览使用临时工程，结束后移除，未操作原工程录音或设置。
