# Immerse Jam 0.1.12

- 优化 Windows 音乐库、分类筛选与卡片，分类管理并入左侧栏。
- 重新分配侧栏纵向空间，保留原有宽度与分区顺序。
- 修正设备互传关闭处理，统一预备拍下拉样式。
- 附件和乐谱增加删除菜单，创作音轨增加铅笔改名、录音移回库和整组删除，统一 S/M。

Windows 版本为 0.1.12。Android 保持 0.1.0-preview.3，本次附上此前已实机验收的更新测试包（ARM64 / x86_64）。

沿用此前完成的针对性检查；最后的侧栏纵向调整按作者要求只构建，不追加界面测试。
