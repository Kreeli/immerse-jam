# 桌面分类布局、波形与录音修复验收

本轮按作者新反馈修改 PC，保留同学 PR 的主题与既有操作逻辑。没有发布 Release、推送应用修改或更新网站。

## 修改

- 音乐库与分类页增加列表 / 方格切换，偏好保存在本机。分类项目的封面与文字固定横向排列，缺少艺人显示短横线，避免旧纵向布局造成错位。标题与艺人过长时省略，列表布局减少占用。
- 波形按整段真实峰值留出更明显的上下空间；不改变音量、原音频或峰值数据，不做百分位削峰。实时录音的单独显示增益保留。
- Windows 取消系统标题栏，最小化 / 最大化与还原 / 关闭放在应用右上角。应用标题区域与左侧品牌区可拖动，按钮和输入区域不拖动；窗口仍可缩放。导出与侧面板开关移至视图工具栏右端，为标题和窗口按钮留出空间。网页演示和 Android 不显示桌面窗口控件。
- 录音启动前检查保存的设备是否仍存在；失效时打开设置、仅恢复失效的设备到系统默认并清除旧链路延迟，用户确认后再开始。隐藏权限下的空设备列表不视为设备丢失。设备在检查后断开也可返回设置；权限和占用错误显示可理解的提示。确认成功后才保存新设备设置，不在后台替用户改写原工程。

## test2 调查

使用本机 `test2` 的完整隔离副本，并复制原应用浏览器配置来保留设备标识上下文。当前设备列表中，保存的 Communications 输入存在，但保存的指定伴奏输出不存在。旧实现先执行 `setSinkId`，因此会在采集前失败。

新版提示重新确认输出设备；使用当前真实输入、系统默认输出完成短录音，副本新增有效录音约 1.89 秒。原工程 manifest 的 SHA-256 与测试前完全一致，没有修改原设备设置、既有录音或曲库。

设备标识可能随设备连接或应用配置变化；这项检查验证当前机器状态，不推断硬件永久损坏，也不保证所有外置声卡组合均已试听。

- TypeScript、1060 项翻译、桌面语法、改动文件格式与前端构建。
- 一项设备选择单元检查：失效输入 / 输出、有效设备、权限隐藏列表、旧延迟清理与原设置不被修改。
