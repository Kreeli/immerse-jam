# Fabulous rehearsal excerpt

Recording supplied by the repository author: rehearsal on the morning of the October 31 performance, covering BLU-SWING's **Fabulous**. This is a rehearsal recording, not the commercial master. Composition and third-party rights remain with their respective owners.

The first five seconds were removed. This demo uses the following 60 seconds (00:05–01:05 of the source recording). The source file is retained locally without modification.

`original.mp3` is the rehearsal mix. The other six MP3s are the output of Immerse Jam's default **BS RoFormer SW** six-stem model. All seven files have the same shared gain adjustment and short boundary fades; stems are not normalized individually. Web copies use 44.1 kHz stereo, 160 kbit/s MP3 (about 1.2 MB each).
