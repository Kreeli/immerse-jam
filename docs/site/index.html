PRACTICE

练琴，是这个工具的老本行。

从「以这首歌创建」新建跟练，在右侧控制台关掉你要弹的声部，其他部分自动成为伴奏。难点段落设个循环，速度调到 0.5 慢慢啃，熟了再回到原速。

  • 每个声部独立音量、声像，支持「选听」和「关闭声音」
  • 变速 0.5×–2×，独立移调，循环段落与标记点
  • 智能节拍器跟随检测节拍，也可手动 BPM、Tap 校准
  • 录音和伴奏波形上下对齐，回听时一眼看出抢拍还是拖拍
  • 「跟拍测延迟」校准录音对齐（戴耳机测才准）

KNOW THE LIMITS

能做到什么，
不能做到什么。

这工具还在持续更新。好用的地方不多吹，
做不到的地方直接写在这里。

01 / 录音与延迟

测延迟要戴耳机。
外放加内置麦克风不适用。

外放的伴奏会被麦克风再收进去，回声和串音会让延迟估计完全失真。跟拍估计里也包含人自己的反应误差，不是声卡的纯硬件延迟。

录音偏晚填正数、偏早填负数，先试听再应用。微调只能修正对齐，去不掉已经录进去的回声。

02 / 自动识别

识别给的是起点，
最后还得靠耳朵。

复杂和弦、强混响、弱起、自由速度、变拍，都可能让和弦和节拍识别翻车，结果可能需要手动改。分轨也可能残留别的乐器声音，没有模型能对每首歌都干净。

好在和弦、小节、BPM、同步点都能手动修正，不同模型的结果可以切换对比。

03 / 移动端与计算

分析在电脑做，
手机负责练。

手机端不做也不打算做本机分轨、节拍识别这类推理，项目同样不提供服务器云计算。Windows 分析一次，手机接收完整项目，或者导入已有伴奏和分轨来用。

Android 还在迭代，暂时不会和桌面端功能完全一致。

FAQ

常见问题。

还有疑问？去 GitHub 提个 issue ↗
真的完全免费？有什么限制？+

免费使用，没有会员、没有分离次数限制，也不需要买云算力。原创代码采用 PolyForm Noncommercial 1.0.0 许可，允许非商业使用、修改和分享，商用请联系作者。第三方组件和模型遵循各自的许可。想支持作者可以自愿打赏，不影响任何功能。

需要什么电脑？必须有 NVIDIA 显卡吗？+

Windows 10 / 11 x64，支持 CPU 和 NVIDIA 两种运行方式，没有 N 卡也能用，速度取决于硬件和模型。安装向导会自动准备好运行环境和模型，不用自己装 Python 或 Node.js。首次准备需要联网和几 GB 磁盘空间，之后可以完全离线使用。

我的歌会被上传吗？+

不会。分离、节拍／和弦识别、乐谱对齐全部在你自己的电脑上跑，曲库、分轨、录音都存在本地数据目录。只有你主动用互传分享项目时才有设备间传输。仅首次下载运行库和模型需要联网。

模型怎么选？可以换吗？+

可以随时换。默认推荐六轨 BS RoFormer SW，效果和速度比较均衡；配置低就用轻量四轨，吉他曲可以试主奏／节奏吉他模型。同一首歌的每个模型结果都独立保存，切换对比后再挑顺耳的用。有自己的模型也能导入。

练吉他／贝斯／唱歌，怎么设置比较顺？+

分析后新建跟练，右侧控制台关掉你要练的声部，其他留着当伴奏。点两下循环按钮设好起止，速度调慢开始练；需要时单独移调。录音前先选好输入设备、伴奏输出和声道，录一小段回听确认没问题再正式开始。

「只录乐器」和「声卡已混音」怎么选？+

输入里只有乐器就选「只录乐器」，伴奏不会混进录音。如果声卡或效果器已经把伴奏和乐器混在一起送进来，就选「声卡已混音」，这样回听时不会叠两遍伴奏。

延迟校准怎么做才靠谱？+

戴耳机，别用外放。先听四拍，再跟着八拍敲一下或扫一下弦，输入只收你的跟拍声。测出来的值包含人的反应误差，应用前先试听校正前后。换耳机、换声卡、换路由之后重新测一遍。

Android 版和 Windows 版差多少？+

Android 目前是预览版，覆盖播放、跟练、创作、录音和导出，不做本机分轨和识别。在电脑上分析完，通过 Wi-Fi 互传或 .ijam 文件发到手机即可。两端工程格式相同，练习设置随项目走。

能替代专业 DAW 吗？+

定位是分轨跟练和轻量多轨创作，不追求替代完整的专业录音软件。蓝牙、USB 声卡、效果器这些组合的录音表现取决于设备和驱动，长时间录制前先做一次短录音确认。
