01 / 录音与延迟

校准请戴耳机。
外放 + 内置麦克风不适用。

外放的节拍与伴奏会被麦克风再次收进来，产生回声与串音，让延迟估计失真。请使用耳机，并让输入只接收你的演奏或跟拍；声卡的 AUX / Loopback 也不要混入校准点击声。

跟拍估计包含人的反应误差，不是声卡纯硬件延迟。先试听，再应用；录音仍不齐时，可对单条录音做时间微调。微调只能调整对齐，不能消除已经录进去的回声，也不会降低实际监听延迟。

02 / 自动识别

识别给你起点，
最后还要相信耳朵。

复杂和弦、强混响、密集编曲、弱起、自由速度与变拍，都可能让和弦或节拍识别不好用。自动识别结果可能需要修改，甚至不适合直接采用。

可以手动修正和弦、小节、BPM 与同步点。分轨也可能残留其他乐器的声音，不保证无损、完全干净，或对每首歌都有同样效果。

03 / 移动端与计算

电脑负责分析。
手机专注把音乐练好。

手机端不会推出本机分轨、节拍识别或自动对齐推理，也不考虑通过服务器提供云计算。分轨与分析交给 Windows 本机，手机接收完整项目，或导入已有伴奏与分轨来使用。

移动端仍在迭代，不承诺与桌面端功能完全一致。旧预览包中的移动推理描述是历史能力，不代表后续产品方向。

延迟估计和录音微调，怎样用才靠谱？+

请戴耳机，不要用外放 + 设备内置麦克风做跟拍延迟估计。外放声音会再次进入麦克风，形成回声和串音；通过 AUX / Loopback 回送的点击声也会影响结果。先听四拍，再跟八拍发出短促扫弦或拍手声，输入应只接收你的跟拍。

估计值包含音频路径延迟与人的跟拍偏差，不是硬件测量值。录音偏晚填正数，偏早填负数；先试听校正前后再应用，并按输入 / 输出组合保存。更换耳机、声卡或路由后重新校准；对已录内容可用单条录音的「时间微调」修正开始时间与偏移。微调不能去掉回声，也不能修好整段忽快忽慢的演奏。

真的免费吗？有没有次数限制？+

免费使用，没有会员或分离次数限制，也不需要购买云端计算额度。侧栏支持作者为自愿打赏，不影响功能。原创代码采用 PolyForm Noncommercial 1.0.0，允许协议范围内的非商业使用；商业用途请联系作者。第三方组件与模型遵循各自许可。

需要什么电脑？必须有 NVIDIA 显卡吗？+

Windows 10 / 11 x64。支持 CPU 与 NVIDIA 运行方式，没有 NVIDIA 显卡也可以使用，处理速度取决于硬件和模型。安装向导会准备运行环境与所选模型，无需自己安装 Python 或 Node.js。首次准备需要联网并预留数 GB 空间，完成后可离线处理。

歌曲会上传到服务器吗？+

Windows 的分离、节拍／和弦识别与乐谱对齐在本机运行，曲库、分轨和录音保存在你的数据目录。只有你主动分享项目时，才会进行设备间传输。首次下载运行库与模型需要网络。

练吉他、贝斯或唱歌，应该怎么设置？+

分析后新建跟练，在右侧控制台关闭要练的声部，保留其他伴奏。点两次循环按钮设置起止，调低速度后练习；需要时独立调整音调。准备录音时选好输入、输出与声道，先做一次短录音确认声音。应用不将麦克风直接返送扬声器，可使用声卡或效果器直接监听。

「只录乐器」和「声卡已混音」怎么选？+

输入只有乐器时选「只录乐器」，内部伴奏不会混进录音。如果声卡／效果器已经把伴奏和乐器混合输出，选「声卡已混音」，避免回听时叠加两遍伴奏。切换耳机或设备后可重新校准；跟拍测延迟包含人的跟拍偏差，不是纯硬件延迟。

Android 能用吗？和 Windows 有什么区别？+

已有 Android 手机／平板预览包。手机端定位是播放、跟练、创作和导出，不提供也不计划提供本机推理，包括分轨、节拍识别与自动对齐；也不考虑提供服务器云计算。请在 Windows 本机完成分析，再通过完整 .ijam 项目或局域网互传到移动设备，也可导入已有伴奏与分轨。

网站截图来自 Windows，移动端仍在迭代，不代表已覆盖全部功能。旧版预览包曾包含移动推理，相关历史说明不代表后续方向。下载时请核对对应 APK 的版本说明，升级或卸载前先导出重要项目。

设备互传等于云同步吗？跨网一定能连接吗？+

互传是项目复制，不是云端自动同步，不会自动合并不同设备的编辑。建议先用同一 Wi-Fi / 热点传输；远程直连受 NAT、运营商与网络条件影响，不能保证跨网连接成功，也没有保证可达的 TURN 中转。连不上时，可以改用局域网或手动传递完整 .ijam 文件。

它能替代专业录音软件吗？什么设备都能录吗？+

Immerse Jam 主要服务分轨跟练和轻量多轨创作，不承诺替代完整的专业 DAW。录音与监听效果取决于设备、驱动和连接方式；尤其是蓝牙、USB 声卡、效果器及手机组合，需要按实际设备验证，不能承诺所有组合都稳定或低延迟。开始长时间录制前，先做一次短录音并回听确认。

分轨、节拍和自动对齐会完全准确吗？+

效果取决于歌曲、混音与所选模型，可能存在残留或串音。复杂和弦、自由速度、弱起与变拍曲目可能需要手动修正。不同模型的分离结果独立保存，可以切换比较，选择更适合这首歌的结果。
